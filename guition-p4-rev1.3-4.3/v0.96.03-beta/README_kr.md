# StajPilot v0.96.03-beta — Guition JC4880P443C_I_W

**이건 베타 버전입니다.** 현재 안정 버전인 [v0.96.01](../v0.96.01)보다 최신이지만
검증은 덜 됐습니다. 아래 새 기능이 필요하지 않다면 지금은 v0.96.01을
쓰는 게 더 안전합니다.

## v0.96.01 이후 달라진 점

- **수정: 하위 MIDI 기기(2인치 보드, 또는 미디캡틴/파이스위치 기기)가 보드의
  USB 호스트 브릿지에 연결되어 있을 때, 딜레이/리버브 켜짐/꺼짐 표시가
  틀리게 나오던 문제를 고쳤습니다.** 하위 기기가 연결되는 순간 보드가
  잠깐 정확한 딜레이/리버브 값을 못 믿게 되어, 실제로는 켜져 있는데도
  화면엔 꺼진 채로 계속 남아있을 수 있었습니다. 하위 기기가 연결되는
  바로 그 순간에 이 부분의 확인 상태만 다시 초기화하도록 고쳤고,
  화면의 다른 부분은 전혀 건드리지 않습니다.
- **부팅/대기 화면에 펌웨어 버전 표시 (신규)** — 좌측 상단에 표시되어,
  지금 어떤 버전이 실행 중인지 한눈에 확인할 수 있습니다.

## 알려진 제한사항

- USB 호스트 모드는 비교적 새로 추가된 기능이라, 변경 없이 그대로
  작동하는 Device 모드 켐퍼 플레이어 연결에 비해 실사용 검증이 상대적으로
  부족합니다. 어떤 USB 모드를 선택하든 기존 Device 모드 연결 자체는 그대로
  작동합니다.
- DEVICE → HOST 전달은 (양방향 모두) 메시지 필터링이 없습니다 — 오가는 내용을
  그대로 전부 전달합니다.
- HOST 모드는 MIDI 클래스 USB 기기를 인식하는 방식이며, 개발 중 사용 가능했던
  기기 외의 모든 USB MIDI 기기로 테스트되지는 않았습니다.
- 다른 양방향 MIDI 컨트롤러와의 연결 안정성은 계속 테스트 중입니다 — 기기에
  따라 동작이 다를 수 있습니다.

## 파일

- `stajpilot_v0.96.03-beta_JC4880P443C_I_W_update_firmware.bin` — 앱만
  업데이트합니다. 이미 정상 작동하는 기기가 있다면 이걸 사용하세요 — 곡 목록,
  WiFi 설정 등 저장된 내용이 그대로 유지됩니다.
- `stajpilot_v0.96.03-beta_JC4880P443C_I_W_factory_merged.bin` — 전체 이미지
  (부트로더 + 파티션 테이블 + 앱). 최초 설치나 완전 복구 시에만 사용하세요 —
  **저장된 곡/WiFi 설정이 모두 지워집니다.**

이 링크는 "Guition JC4880P4 (BETA)"로 바로 열립니다 - 화면에 나오는 안내를
따라가세요, 보드를 업로드 모드로 진입시키는 방법까지 전부 안내됩니다.

## 플래시: 일반 업데이트 (곡/WiFi 설정 유지)

```
esptool.py --chip esp32p4 --port <PORT> --baud 460800 \
  write_flash 0x10000 stajpilot_v0.96.03-beta_JC4880P443C_I_W_update_firmware.bin
```

플래시 오프셋 `0x10000`. 파티션 테이블을 쓰지 않고, SPIFFS/NVS도 포맷하지 않습니다.

## 플래시: 최초 설치 / 복구 (SPIFFS + NVS 초기화)

```
esptool.py --chip esp32p4 --port <PORT> --baud 460800 \
  write_flash 0x0 stajpilot_v0.96.03-beta_JC4880P443C_I_W_factory_merged.bin
```

플래시 오프셋 `0x0`. 부트로더는 `0x2000`, 파티션 테이블은 `0x8000`, 앱은
`0x10000`에 위치하며 하나로 병합된 이미지입니다. 최초 설치/복구 시에만 사용하세요.
